# Módulo 0 · Primera ejecución

Abre esta carpeta en tu herramienta y pega este prompt tal cual:

```
Lee AGENTS.md y recorre el repositorio. Luego respóndeme tres cosas:
1. El mapa de mi Marketing OS: qué módulos existen y cuáles están vacíos.
2. Las tres primeras preguntas que debo responder en 01-contexto/marca.md.
3. Qué skill tienes disponible y cuándo lo usarías.
No cambies ningún archivo todavía.
```

## Quedó funcionando si

- [ ] El agente nombra los módulos 00 a 05 y te dice que están por llenar.
- [ ] Te hace preguntas sobre tu marca en lugar de inventar respuestas.
- [ ] Menciona el skill `auditar-brief`.

Si algo falla, toma una captura de pantalla y llévala a clase.
