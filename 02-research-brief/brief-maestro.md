# Brief maestro

Un brief es un contrato. Estos son los ocho bloques que este equipo exige antes de producir. Ajusta los pesos a tu criterio: deben sumar 100.

| Bloque | Qué debe responder | Peso | Mínimo para aprobar |
| --- | --- | --- | --- |
| 1 · Definición del problema | El problema de negocio, con un número |  |  |
| 2 · Fuente de crecimiento | De dónde viene el crecimiento: nuevos compradores, frecuencia, precio |  |  |
| 3 · Comportamiento de compra | Cómo y cuándo se compra la categoría |  |  |
| 4 · Datos del comprador real | Evidencia, no un perfil imaginado |  |  |
| 5 · Línea base de marca | Dónde está la marca hoy |  |  |
| 6 · Inversión y competencia | Presupuesto y presión competitiva |  |  |
| 7 · Restricciones operativas | Tiempos, aprobaciones, legales |  |  |
| 8 · Gobierno de la medición | Qué KPI, quién lo reporta y cada cuánto |  |  |

## Reglas
- Puntaje mínimo para arrancar producción: ___ de 100.
- "No tenemos ese dato" es una respuesta válida: se anota como vacío declarado y pasa a la agenda, no se deja en blanco.
- Quién puede aprobar un brief por debajo del mínimo: ___.
