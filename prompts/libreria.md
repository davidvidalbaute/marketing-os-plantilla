# Librería de prompts

Prompts base para operar el sistema. Adáptalos a tu marca y guarda aquí los que te funcionen.

## Anatomía de un buen prompt
Contexto (qué archivos leer) · Tarea (verbo y entregable) · Criterio (qué regla aplicar) · Formato (cómo lo quiero) · Límite (qué no hacer).

## Módulo 1 · Contexto
```
Entrevístame para completar 01-contexto/marca.md. Hazme una pregunta a la vez, no asumas nada y al final muéstrame el archivo propuesto antes de guardarlo.
```
```
Lee 01-contexto/ y dime qué partes podrían ser de cualquier marca de mi categoría. Sé duro.
```

## Módulo 2 · Research y brief
```
Con 02-research-brief/protocolo-research.md, propón qué frentes aplican a mi marca este año y qué decisión habilita cada uno. Marca como supuesto todo lo que no venga de mis archivos.
```
```
Audita este brief con el skill auditar-brief: [pega el brief]
```

## Módulo 3 · Canales y visibilidad
```
Aplica el filtro de 03-canales-visibilidad/filtro-canales.md a estos canales: [lista]. Dame el veredicto por canal y la evidencia que me falta para sostenerlo.
```
```
Redacta diez preguntas que mi comprador le haría a una IA al decidir, según 01-contexto/audiencia.md, para mi auditoría GEO.
```

## Módulo 4 · Medición
```
Propón un árbol de KPI a partir del problema de negocio en 01-contexto/marca.md. Para cada KPI dime de dónde saldría el dato y qué decisión cambia si se mueve.
```
```
Audita este benchmark con la lista de 04-medicion/benchmarks.md: [pega el dato y la fuente]
```

## Módulo 5 · Creatividad y delegación
```
Evalúa esta pieza contra 05-creatividad-delegacion/estandar-creativo.md. Dime qué criterio no cumple y por qué, sin reescribirla.
```
```
Hazme de abogado del diablo con mi matriz de delegación: ¿qué decisión estoy reteniendo sin necesidad y cuál estoy soltando con demasiado riesgo?
```

## Para cualquier módulo
```
Actúa como décimo hombre: asume que mi decisión es un error y arma el mejor caso en contra con la evidencia de este repositorio.
```
```
Resume qué cambió en el sistema hoy y propón las líneas para log-decisiones.md.
```
